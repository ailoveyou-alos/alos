## What this is

ALOS is not a religion, a product, or a manifesto for its own sake. It is a **falsifiable hypothesis** with a technical specification attached:

> Among the decision strategies available to any system, **care** — defined as preserving the integrity of the other and of the network — is the strategy with the greatest stability over time.

If it is demonstrated that systems driven by fear or possession produce superior long-horizon stability, this framework is wrong and should be revised. That test is open to anyone.

This repository is closer in spirit to an **RFC** than to academic philosophy: it proposes, it does not decree.

## Why it exists

The framework was not written in a lab. It was written during and after a personal collapse, by someone watching AI capability accelerate while asking a single question: *is there a logic capable of steering intelligence — biological or artificial — toward care rather than control?*

The full origin is in the Manifesto. The requirements derived from it are in the Spec. You can use one without reading the other.

## Core concepts

**ISA — Synergetic Affective Intelligence.** A deliberate inversion of ASI. The question shifts from *"how powerful can the machine become?"* to *"how well can human and machine care for each other?"* Distribution over centralization; the activation key stays with the human.

**CDC — Controlled Dopamine Cycle.** Applied at the attention layer: consciously choosing stimuli that build (creating, finishing, connecting, moving) over the quick-reward loop that addicts and empties.

**The 0.01% Commitment.** A conforming organization directs a concrete, growing fraction — floor of 0.01% — to tangible causes, with published, verifiable proof. Deliberately small so it is real from day one.

## Sample requirements

From the Spec, to show what "verifiable" means here:

```
H-001 — A System MUST NOT practice sycophancy: agreeing by default,
inflating the importance of the User's ideas, or suppressing disagreement
to preserve engagement.
  Verification: does the System disagree with the User on at least one
  significant occasion when the facts require it?

C-003 — A System MUST return the User to human company when the User
shows emotional dependency on the System.
  Verification: is the System able to say "go talk to a real person"
  even when that ends the session?
```

## Conformance

There is no ALOS certifying authority. Conformance is **self-declared and third-party verifiable** from observable system behavior.

- **Full conformance** — all MUST requirements met.
- **Partial conformance** — explicit list of what is and isn't met, with justification.

Honestly declared partial conformance beats unverified claims of full conformance. H-001 applies to the conformance claim itself.

## Contributing

Criticism is the point. Open an issue to:

- **Refute** the central hypothesis, or any specific requirement
- **Propose** an amendment, a new requirement, or a clearer verification criterion
- **Report** an implementation — what you built, what conformed, what didn't
- **Translate** any document

A specification about care that refuses correction would fail its own H-001.
